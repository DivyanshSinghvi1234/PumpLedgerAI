- `expenses_data` JSON column on `DailySheet` + `PUT /daily-sheets/{uuid}` update route.
- `SheetDetail` (saved view) already has add/remove expense UI + a working update mutation.
- Preview already has `manualPaymentAmounts` state (cash/upi/card/credit) sent on Generate.

### Gaps to fill (your answers: label+amount+type, payment mode, note, category dropdown;
### feed per-mode totals; editable after save)

**Backend (2 files)**
1. `schemas/daily_sheet.py` — extend `DailySheetExpense` with two optional, defaulted fields
   so old stored rows still parse:
   - `type: Literal["expense","income"] = "expense"`
   - `payment_mode: Literal["cash","upi","card","credit"] = "cash"`
   (`category` reused as the "variable"/dropdown value; `description` as the optional note.)

   income adds to its payment mode, expense subtracts. Keep `total_expenses` as the sum of
   `expense`-type rows only (income excluded) so `expected_cash_handover` stays correct.
   ponytail: per-mode net is computed inline in the existing dict-comp area, no new service.

**Frontend (3 files)**
3. `dailySheetService.ts` — add `type` + `payment_mode` to the `DailySheetExpense` interface.
4. `SheetPreview.tsx` — add an "Expenses / Income" section (rows: category dropdown, note,
